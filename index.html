Core Components

Risk Management (4 Layers)

Layer 1: Pre-Trade Validation

  • 9 independent checks gate every order
  • Daily loss limit: $500/account
  • Single trade risk cap: $150
  • Max 2 open positions per account

Layer 2: Dynamic Position Sizing

  • Base: 1 ES/NQ contract
  • Scale up only with $1,500+ profit buffer
  • Confidence-weighted from signal quality

Layer 3: Circuit Breakers

  • 30% DD used → reduce size
  • 50% DD used → minimal size only
  • 70% DD used → HALT + emergency flatten

Layer 4: Portfolio Aggregation

  • $5,000 cross-account daily loss limit
  • Max 10 simultaneous positions total
  • Correlated instrument exposure limit

Trading Strategies

1. VWAP Mean Reversion

  • Edge: Price reverts to VWAP in range-bound sessions
  • Entry: 1.5+ ATR deviation + reversal candle
  • Win rate target: 60-70%
  • Best: Regular hours, choppy markets

2. Opening Range Breakout

  • Edge: Institutional flow at RTH open
  • Entry: 15-min range breakout + volume surge
  • Win rate target: 45-55%
  • Best: Trend days, news catalysts

3. Momentum Scalp

  • Edge: Short-term momentum persistence
  • Entry: 8/21 EMA cross + RSI + volume
  • Win rate target: 50-60%
  • Best: Trending sessions, high volume

Copy Trading — Detection Avoidance

7 techniques make 20 accounts appear independent:

  • Timing jitter: Gaussian 0.5-5.0s delays
  • Size variance: ±20% per account
  • Skip probability: 10% random skip
  • Account grouping: 4 groups of 5, one active
  • Strategy rotation: Different combos per group
  • Price variance: ±2 ticks on limits
  • Random ordering: Shuffled each signal

Webhook Signal Flow

1
TradingView alert fires — Pine Script generates JSON payload with strategy, action, price, stops
2
Webhook server receives — Validates token, checks signal age (<30s), rate limits
3
Copy engine distributes — Selects active group, applies variance, staggers execution
4
Risk + Compliance check — Each account validated independently before order
5
Tradovate execution — Bracket orders placed with account-specific parameters

Quick Start

1
Clone the repo and install: pip install -r requirements.txt
2
Copy .env.example to .env and configure credentials
3
Copy config/accounts.example.json and add your 20 accounts
4
Deploy Pine Script strategies to TradingView and configure webhook alerts
5
Start in dry run: python main.py
6
Go live: python main.py --live --accounts config/accounts.json
